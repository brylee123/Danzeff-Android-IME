# Using Danzeff

Enable **Danzeff Keyboard** in Android's keyboard settings, then choose it as your current keyboard. You can return to your previous keyboard through Android's keyboard switcher.

## Touch typing

Touch a cell to expand it. Keep your finger down, drag toward a character, and release to type it. You can also tap a cell, lift your finger, then tap a character. The grid resets after each character.

Use the numbers and symbols controls to change pages. Hold Delete to erase repeatedly. Drag Space to move the cursor. Tap **Edit** for selection, copy, cut and paste.

## Controllers and keypads

Connect a Bluetooth or USB controller. Open **Controller & keypad profiles**, choose your device or tap **Detect device from input**, then press a button.

Tap an action to listen for a controller button, stick direction or trigger. Long-press an action to clear its bindings. You can save a copy, rename a profile, choose a saved profile or restore PSP defaults. Each input device has its own profiles, saved automatically on this Android device.

Default controls use the left stick to select a group, with Y/X/A/B for top/left/bottom/right. L1 changes letters and numbers; hold R1 to shift. D-pad up deletes, down inserts a new line, and left/right moves the cursor.

## Appearance and feedback

**App & keyboard appearance** changes every screen and the keyboard. Choose Light, Dark or System (auto). System mode follows Android's appearance setting.

**Typing & feedback** controls local English suggestions, optional autocorrect, capitalization, double-space punctuation and haptics. After autocorrect changes a word on Space, immediately press Backspace to restore the original. Haptics also follow Android's system setting.

## Field behavior

| Field | Keyboard behavior |
| --- | --- |
| Ordinary text | Optional suggestions and smart capitalization |
| Password or private text | Automatic text transformations and suggestions disabled |
| Email and URL | Relevant shortcuts; automatic text transformations disabled |
| Number and phone | Numeric layout; automatic text transformations disabled |
| Editor action | Uses the app's available Send, Search, Next or other action |

Apps can implement text fields differently. Selection and clipboard actions depend on the field's support. This remains an experimental keyboard; real-device compatibility testing is ongoing. [View the compatibility matrix](https://github.com/brylee123/Danzeff-Android-IME/blob/main/docs/COMPATIBILITY_MATRIX.md).

## Privacy and credits

The keyboard works offline and has no internet permission. Typed words are not saved or uploaded. Only settings and controller profiles are saved locally. Suggestions use a small bundled English dictionary.
